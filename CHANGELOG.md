# Changelog

## 1.1.0-extended

This release extends the Minecraft 1.12.2 version of Elenai Dodge 2 while keeping the fork focused on Minecraft 1.12.2.

- Added configurable base and maximum feather values.
- Added layered feather colors for higher stamina values.
- Updated Feathery absorption scaling by potion amplifier.
- Improved absorption feather rendering.
- Updated feather GUI textures.
- Fixed armor weight tooltip icon spacing.
- Added feather limit hooks for RPG, race, class, attribute, equipment, or progression integrations.
- Added dodge cost integration support through `SpendFeatherEvent`.
- Added server-controlled dodge animations for third person and first person using Minecraft Forge 1.12.2 rendering hooks.
- Added first-person camera roll with configurable server-side intensity.
- Added directional dodge particles and tuned dodge sounds.
- Added `/elenaiReload` for OP level 4 config reload and client resync.
- Updated default HUD Y offset and first-person camera intensity.
